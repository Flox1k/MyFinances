# MyFinances - Цифровой кошелёк

Полнофункциональное десктопное приложение для управления личными финансами, разработанное на Python с использованием PyQt5 и SQLAlchemy.

## 📋 Функциональность

### Основные возможности
- ✅ **Регистрация и аутентификация** с безопасным хешированием паролей (bcrypt)
- ✅ **Управление несколькими кошельками** у одного пользователя
- ✅ **Отслеживание доходов и расходов** с комментариями
- ✅ **Историю транзакций** с фильтрацией по типу
- ✅ **Общий баланс** всех кошельков в один клик
- ✅ **Административный интерфейс** для управления пользователями и данными

### Архитектура
Приложение построено с использованием многоуровневой архитектуры:
```
UI (PyQt5) → Services (бизнес-логика) → Repository (БД) → SQLite
```

Это обеспечивает:
- 🔧 **Легкую интеграцию** новых функций
- 🧪 **Тестируемость** каждого слоя
- 🛡️ **Безопасность** - разделение ответственности
- 📈 **Масштабируемость** - готовность к расширению

## 🚀 Установка и запуск

### Требования
- Python 3.9+
- pip (менеджер пакетов Python)

### Шаги установки

1. **Перейти в директорию проекта:**
```bash
cd Diplomka_v1
```

2. **Установить зависимости:**
```bash
pip install -r requirements.txt
```

3. **Запустить приложение:**
```bash
python main.py
```

## 💾 База данных

При первом запуске автоматически создается файл `myfinances.db` с тремя таблицами:

### Таблица `users`
```sql
- id: INTEGER PRIMARY KEY
- username: VARCHAR(50) UNIQUE
- email: VARCHAR(100) UNIQUE
- password_hash: VARCHAR(255)
- created_at: DATETIME
```

### Таблица `wallets`
```sql
- id: INTEGER PRIMARY KEY
- user_id: INTEGER FOREIGN KEY
- name: VARCHAR(100)
- balance: FLOAT
- currency: VARCHAR(3)
- created_at: DATETIME
- updated_at: DATETIME
```

### Таблица `transactions`
```sql
- id: INTEGER PRIMARY KEY
- wallet_id: INTEGER FOREIGN KEY
- type: ENUM(income, expense)
- amount: FLOAT
- description: VARCHAR(500)
- created_at: DATETIME
- updated_at: DATETIME
```

## 🔐 Безопасность

- **Пароли хешируются** с использованием bcrypt (12 раундов)
- **Пароли никогда не хранятся** в открытом виде
- **Валидация входных данных** на каждом уровне приложения
- **Защита от SQL-инъекций** через SQLAlchemy ORM

## 📖 Использование

### Регистрация
1. Запустить приложение
2. Перейти на вкладку "Регистрация"
3. Заполнить: имя пользователя (3-50 символов), email, пароль (минимум 6 символов)
4. Нажать "Зарегистрироваться"

### Вход
1. На вкладке "Вход" ввести имя и пароль
2. Нажать "Войти"

### Создание кошелька
1. После входа нажать "+ Добавить кошелёк"
2. Ввести название кошелька
3. Кошелек создан с нулевым балансом

### Добавление транзакции
1. Двойной клик на кошелек или выделить и открыть окно
2. Нажать "+ Добавить" 
3. Выбрать тип (Доход/Расход)
4. Ввести сумму и комментарий (опционально)
5. Нажать "OK"

### Просмотр админки
1. Нажать кнопку "Админка" на главном окне
2. Просмотреть и управлять: пользователями, кошельками, транзакциями

## 🔧 Модули и классы

### config.py
- Конфигурация приложения (пути, константы, размеры окон)

### models.models.py
- `User` - модель пользователя
- `Wallet` - модель кошелька
- `Transaction` - модель транзакции
- `TransactionType` - enum типов транзакций

### db.database.py
- `init_db()` - инициализация БД
- `get_session()` - получение сессии БД
- `close_session()` - закрытие сессии

### db.repositories.py
- `UserRepository` - операции с пользователями
- `WalletRepository` - операции с кошельками
- `TransactionRepository` - операции с транзакциями

### services.services.py
- `AuthService` - регистрация и вход
- `WalletService` - управление кошельками
- `TransactionService` - управление транзакциями
- `AdminService` - административные функции

### utils.helpers.py
- `hash_password()` - хеширование пароля
- `verify_password()` - проверка пароля
- `validate_email()` - валидация email
- `validate_password()` - валидация пароля
- `validate_username()` - валидация имени пользователя
- `validate_amount()` - валидация суммы
- `format_date()` - форматирование дат
- `format_currency()` - форматирование денежных сумм

### ui.login_window.py
- `LoginWindow` - окно входа/регистрации

### ui.main_window.py
- `MainWindow` - главное окно приложения

### ui.wallet_window.py
- `WalletWindow` - окно кошелька с транзакциями

### ui.transaction_dialog.py
- `TransactionDialog` - диалог для добавления транзакций

### ui.admin_window.py
- `AdminWindow` - административное окно
