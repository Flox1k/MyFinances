# MyFinances - Цифровой кошелёк 💰

Полнофункциональное десктопное приложение для управления личными финансами, разработанное на Python с использованием PyQt5, SQLAlchemy и интеграцией с AI (OpenRouter).

## 📋 Функциональность

### Основные возможности
- ✅ **Регистрация и аутентификация** с безопасным хешированием паролей (bcrypt)
- ✅ **Управление несколькими кошельками** у одного пользователя
- ✅ **Отслеживание доходов и расходов** с комментариями и категориями
- ✅ **Историю транзакций** с фильтрацией по типу и периодам
- ✅ **Мультивалютность** - поддержка KZT, USD, RUB с автоматическим пересчетом
- ✅ **Курсы валют** с возможностью добавления и редактирования
- ✅ **Управление долгами** - отслеживание кредитов и заёмов
- ✅ **Цели и бюджеты** - планирование расходов по категориям
- ✅ **AI Чат** - консультант по финансам на базе нейросети (OpenRouter)
- ✅ **Графики и статистика** - визуализация движения средств
- ✅ **Административный интерфейс** для управления пользователями и данными
- ✅ **Современный дизайн** с поддержкой темной и светлой темы
- ✅ **Готовый .exe файл** - никаких зависимостей не требуется

### Архитектура
Приложение построено с использованием многоуровневой архитектуры:
```
UI (PyQt5) → Services (бизнес-логика) → Repository (БД) → SQLite
```

Это обеспечивает:
- 🔧 **Легкую интеграцию** новых функций
- 🧪 **Тестируемость** каждого слоя
- 🛡️ **Безопасность** - разделение ответственности
- 📈 **Масштабируемость** - готовность к расширению

```bash

```

#### Сборка собственного .exe файла

Если вы хотите собрать exe файл самостоятельно:

```bash

.\.venv\Scripts\Activate.ps1

# 2. Установите PyInstaller
pip install pyinstaller

# 3. Соберите exe
pyinstaller --onefile --windowed --icon=icon_myfinances.png --name=MyFinances main.py

# 4. Файл будет создан в папке dist/
```

## 📚 Архитектура сервисов

### AuthService
- `register(username, email, password, password_confirm)` - Регистрация нового пользователя
- `login(username, password)` - Вход в аккаунт
- `validate_password(password)` - Валидация сложности пароля

### WalletService
- `create_wallet(user_id, name, currency)` - Создание кошелька
- `get_user_wallets(user_id)` - Получение всех кошельков пользователя
- `update_wallet(wallet_id, name, currency)` - Обновление кошелька
- `delete_wallet(wallet_id)` - Удаление кошелька
- `get_total_balance(user_id, currency)` - Общий баланс в одной валюте

### TransactionService
- `add_transaction(wallet_id, type, amount, description, category)` - Добавить операцию
- `get_wallet_transactions(wallet_id, start_date, end_date)` - Получить операции
- `update_transaction(transaction_id, ...)` - Обновить операцию
- `delete_transaction(transaction_id)` - Удалить операцию

### ExchangeRateService
- `set_exchange_rate(user_id, from_currency, to_currency, rate)` - Установить курс
- `get_exchange_rate(user_id, from_currency, to_currency)` - Получить курс
- `convert_amount(amount, from_currency, to_currency, user_id)` - Конвертировать сумму
- `get_user_rates(user_id)` - Все курсы пользователя
- `init_default_rates(user_id)` - Инициализировать дефолтные курсы

### AdminService
- `get_all_users()` - Список всех пользователей
- `get_user_details(user_id)` - Детали пользователя
- `delete_user(user_id)` - Удалить пользователя и его данные

### CategoryService
- `create_category(user_id, name, icon, color)` - Создать категорию
- `get_user_categories(user_id)` - Получить категории пользователя
- `create_default_templates(user_id)` - Создать стандартные категории

### DebtService
- `add_debt(user_id, title, amount, creditor, due_date)` - Добавить долг
- `mark_debt_paid(debt_id)` - Отметить долг погашенным
- `get_user_debts(user_id)` - Получить долги пользователя

### GoalService
- `create_goal(user_id, name, target_amount, currency, deadline)` - Создать цель
- `update_goal_progress(goal_id, current_amount)` - Обновить прогресс
- `get_user_goals(user_id)` - Получить цели пользователя
